状态空间

状态空间

一句话定义

状态空间是某个指定系统的某个指定状态描述所允许的全部状态值的集合。

为什么这个概念重要

状态描述说明携带什么信息向前；状态空间说明该描述有哪些实现值可能或允许。在问「系统如何变化」之前必须作出这一区分：演化是在可取状态值之间移动，而不是在各选变量列表之间移动。

状态空间还固定了后续论断得以解读的论域。它决定什么算一个状态、哪些取值组合被允许，以及所表示的是哪个系统边界与分辨率。Terman 与 Izhikevich 给出了标准表述：状态空间是可能状态的集合，每个状态表示为一个点 (Terman 和 Izhikevich 2008年)。

直觉

先选择一份状态描述。对理想化摆，该描述可能包含角度与角速度。然后设想这两个量的每一个可许赋值。每个赋值是一个状态值，所有这些值的集合就是状态空间。

这个集合比一次实验观测到的状态更广。一次记录可能只访问其中很小的子集，有限数据也只包含采样得到的测量。反过来，并非任意坐标值组合都必须可取：物理约束、逻辑约束或声明的模型边界可能排除某些组合。

因此，状态空间相对于以下三者：

  1. 系统边界 —— 哪些实体与影响位于系统内部；
  2. 状态描述 —— 保留哪些未来相关变量；
  3. 分辨率与可许性约束 —— 模型把哪些区分与组合视为有意义。

坐标约定是另一个独立的表示选择。它为抽象状态空间中的状态值赋予数值坐标。不同的坐标系可以表示相同的基础状态信息，而不改变哪些抽象状态可取。

形式化定义

设一份状态描述指定系统状态值的结构，并设声明的约束决定哪些值可取。状态空间可以写作

\[ \mathcal{X} = \{x : x \text{ is an admissible state value under the specified description and constraints}\}. \]

当状态值由 \(n\) 个坐标表示时，可写 \(x=(x_1,\ldots,x_n)\)。坐标元组是状态值的数值表示；它本身不是抽象状态值或状态空间。不同的坐标系可以表示相同的基础状态值，而可许性约束决定哪些表示值属于 \(\mathcal{X}\)。

该定义要求一组可能的状态值，但不要求特定的运动方程、距离或可视化。在 L1 阶段尚无需指定或论证维数。在 Teschl 的抽象数学表述中，演化作用于一个记为 \(M\) 的集合 (Teschl 2012年, sec. 6.1)；在 LDG 记号中，一旦该集合的点被赋予可取状态值的角色，它便是 \(\mathcal{X}\)。

核心记号

  • \(\mathcal{X}\)：状态空间。
  • \(x\in\mathcal{X}\)：一个可取状态值。
  • \(x(t)\in\mathcal{X}\)：在时刻 \(t\) 被赋予的状态值。
  • \(x=(x_1,\ldots,x_n)\)：当描述使用 \(n\) 个坐标时的坐标表示。

行是记录样本的矩阵在这里不记作 \(\mathcal{X}\)：它是从所提出的状态空间抽取、投影或以其他方式与之相关的数据集。

前置知识

  • State：区分状态描述、状态值与状态向量。

假定背景： 初等集合与向量记号。

与相邻概念的关系

概念 与状态空间的关系
状态描述 指定什么变量或结构构成状态。状态空间包含该描述下的可取状态值。
状态值 状态空间的一个成员 \(x\in\mathcal{X}\)。空间本身不是单一状态。
状态向量 / 坐标 一个状态值的数值表示。坐标选择不定义抽象状态空间，其本身也不决定哪些值可取。不同的坐标可以表示相同的基础状态信息。
观测空间或测量范围 包含可能的传感器输出或测量值。在理想的直接测量下它可以与状态空间重合，但当观测是部分的、有噪声的或间接的时，通常与状态空间不同。
数据集或数据矩阵 包含有限多个记录值。它对观测数据进行采样或表示；它并不自动是所有可取状态的集合。
轨迹 一条以时间为参数、穿过状态空间中状态值的可取演化。空间包含可能状态；轨迹记录一条系统演化穿过它们的过程。
参数空间 包含对模型或演化规则进行索引的备选参数值。即使参数与状态都用向量表示，它们的建模角色也不同。
潜空间 为未观测或推断变量引入的坐标域。只有当其值被赋予指定演化的充分状态角色时，它才是状态空间。
相空间 在动力学系统语境中常作为状态空间的同义词使用。用法因领域而异，因此 LDG 要求陈述预期的状态描述与可取状态值，而不是仅依赖标签。

这并不蕴含

把某个集合称为状态空间，其本身并不蕴含：

  • 每个可取状态都已被观测或可以观测；
  • 记录样本稠密或无偏地覆盖空间；
  • 每个坐标都是直接测量；
  • 该空间等同于数据矩阵、点云或绘制的投影；
  • 所有坐标组合都可取；
  • 表示是唯一、最小、低维或欧氏的；
  • 已论证特定的距离、几何或邻域关系；
  • 已识别演化规则、轨迹或因果机制；或
  • 模型定义的空间是真实系统的完整物理状态空间。

最小示例

对摆的描述

\[ x=(\text{angle},\;\text{angular velocity}), \]

一个状态值是由角度与角速度指定的摆的某一种特定状态。抽象状态空间是所选摆描述及其物理假设所允许的全部此类状态的集合。

选择弧度而非度、选择角速度单位或使用另一种等价的数值编码，改变的是坐标表示，而非可取摆状态的基础集合。

包含 1,000 个相机样本的表格不是该状态空间。它是观测的有限集合。即使从每一帧估计出角度与角速度，得到的 1,000 个状态估计也只显示那次记录期间采样到的值，而不是全部可取的摆状态。

神经科学 / 行为相关性

对 \(D\) 个记录神经元，群体活动常用 \(D\) 个发放率坐标表示；每个时间点于是是对应群体坐标域中的一个点 (Cunningham 和 Yu 2014年)。有限个记录的群体向量是数据，并不自动是完整的神经状态空间。把该坐标域称为神经状态空间，还意味着分析承诺把那些群体变量视为对某个声明系统与时间尺度的状态描述。

同样，姿态估计矩阵或行为特征集合也不自动是行为状态空间。所提出的空间必须说明哪些特征组合可取，以及为什么这些特征构成状态而非部分观测。低维潜表示仍然依赖模型与准则；仅靠其可视化并不确立唯一的基础状态空间。

对 LDG 的意义

LDG 将反复比较记录变量、潜坐标与所提出的动力学描述。状态空间语言把三个对象分开：状态描述、可取状态值的集合，以及用于研究它们的有限数据。只有在轨迹或初始条件能被一致地定义之前需要这一分离，也只有在后续工作能对潜结构作出站得住脚的主张之前需要这一分离。

开放问题

  • 什么经验证据能表明所提出的状态空间排除了预测所需的状态值？
  • 哪些表面上的约束反映系统本身，哪些反映采样或测量限制？
  • 当两种坐标表示相同未来相关信息时，什么使其中一种在科学上更可取？

这些是与模型和数据集相关的后续问题，而不是扩大 L1 定义的理由。
