非线性重构与图几何鲁棒性基准测试

非线性重构与图几何鲁棒性基准测试

科学问题

P4-U05 询问两个独立合成问题。

  1. 非线性重构： 在声明弯曲生成器与有界对照下，训练均值、秩一 PCA/线性自编码器、小非线性自编码器与冻结随机编码器对照何时重构留出观测或无噪信号，以及其码如何响应曲率、矩匹配全维高斯、样本/容量压力、干扰方差与支撑移位？
  2. 图几何： 对已知发卡或圆模拟器，外围线性参考、经典 MDS、Isomap、直接图诊断、扩散映射与冻结样本外扩展如何响应采样间隙、捷径、非均匀密度、图连通性、邻域大小、带宽、谱截断与特征度量缩放？

任务具有单独生成器、方法、信息集、适用性规则、度量、摘要与图面板。不计算跨任务归一化、聚合得分、排名或普遍胜者。重构损失、码诊断、图路径误差、算子特征空间误差与留出扩展误差是不可互换目标。

真值

重构任务

普通重构场景使用标量评分变量 \(s\in[-1.5,1.5]\) 与六维无噪映射

\[ f_c(s)=\left[ s, cs^2, 0.35c\sin(2s), 0.2cs^3, c\left(\cos s-\frac{\sin(1.5)}{1.5}\right), 0.4c\sin(3s) \right], \]

其中 \(c\) 是声明曲率。随后添加标准差 \(0.06\) 的独立高斯观测噪声。高方差干扰场景向后两个观测坐标添加标准差 \(2.4\) 的独立噪声。已知 \(s\) 与 \(f_c(s)\) 是仅评分真值；它们不被提供给预处理、拟合、选择或重构。

矩匹配高斯场景改为采样参考弯曲信号加观测噪声的总体均值与协方差的满维高斯。它没有标量生成器参数或无噪一维信号目标，因此那些行显式不适用。

一维瓶颈宽度由分析者固定。它不是与模型无关的本征维数估计，生成曲线也不被用作任意观测位于流形上的证据。

图几何任务

发卡生成器使用稳定 Phase 3 单位速度平面发卡，等距嵌入三个观测维并添加标准差 0.01 的高斯噪声。其评分真值是解析弧长坐标 \(\ell\)。普通半径继承自稳定 Phase 3 实现；捷径压力使用半径 0.06。图构造只接收观测坐标。弧长在拟合后进入图或扩展评分。

圆生成器使用 \((\cos\theta,\sin\theta)\) 的稳定 Phase 3 三维等距嵌入。有限目标是声明训练亲和/马尔可夫算子及其余弦–正弦双模态子空间、完整有限算子扩散距离与冻结 Nyström 扩展。这些是有限图/算子目标，不是推断拓扑或恢复黎曼度量。

生成

生成先于拟合且划分特定。

  • 重构训练/验证/测试大小为 120/60/90，除样本/容量压力（28/42/90）。普通 \(s\) 值在每个划分内独立均匀于 \([-1.5,1.5]\)。在 support_shift 中，训练与验证精确为参考捆绑，而测试幅度在 \([1.5,2.35]\) 中随机符号采样。
  • 发卡训练/验证/测试大小为 108/42/54。采样在弧长中均匀，除非场景声明训练间隙或非均匀密度。度量缩放场景在应用 diag(1,1,3) 前重用参考随机抽样。
  • 圆训练/验证/测试大小为 64/32/64。均匀训练点形成相移正则网格；非均匀训练角度使用均匀抽样的固定幂变换。在每个圆场景与重复中，每个测试角度是两个连续排序训练角度（含环绕区间）之间的精确圆中点。验证是独立保留网格，不用于拟合或选择。度量缩放对相同参考训练/测试角度应用 diag(1,1,3)。

两个 Phase 3 源角色刻意不同。稳定非线性重构可执行是仅哈希设计出处：它不在运行时加载，且没有 P3_NL 数值调用。稳定图几何可执行被加载并实际复用于发卡几何、图拟合、最短路径/MDS、扩展、扩散映射、Nyström 与算子诊断。清单与验证诊断分别记录这些角色；两个稳定 Phase 3 源都不被修改。

阴性对照与压力情形

  • 矩匹配高斯在移除声明标量/无噪重构目标的同时控制第一与第二矩。
  • 冻结随机编码器固定其编码器并只训练其解码器，把有用随机非线性特征与学习编码器分开。
  • 高容量/小样本与干扰场景暴露架构与损失组成敏感性，而不强迫特定失败故事。
  • support_shift 使用精确参考训练/验证观测与精确相同拟合状态；只有外部支撑测试捆绑不同。
  • 发卡间隙与 \(k=1\) 保留断开图与无限最短路径对，而非静默修复连通性。
  • 减小支分离、大/近完整邻域与特征缩放暴露捷径与度量依赖。
  • 圆密度、带宽与度量缩放场景压力有限马尔可夫算子、谱截断与冻结 Nyström 扩展。

失败与不适用保留在原始笛卡尔结果清单中，检查后不被调走。

重复与确定性种子

每个场景在主种子 20260820 下使用三个独立确定性重复。种子词语包括任务、稳定 SHA-256 推导场景代码、重复、阶段、划分与相关处候选。场景-重复内方法共享生成数据以配对描述性比较。

三个重复只支持有界描述性 q10/中位数/q90 摘要。它们不提供置信区间或稳定尾部估计。

划分纪律

重构

  • 训练观测拟合标准化器、均值与 PCA/解析线性自编码器。
  • 训练与验证观测拟合非线性自编码器与冻结编码器对照的两个确定性候选种子；验证 MSE 以确定性索引并列打破选择一个候选。
  • 测试观测只传给冻结重构。
  • 测试 \(s\) 与无噪信号只在评分中加入。
  • 支撑移位场景重用精确参考训练/验证观测与拟合状态。验证器记录零拟合状态差异。

图几何

  • 只有训练观测构造发卡图或圆算子。生成验证划分被保留，但在该有界实现中不用于超参数选择。
  • 训练真值仿射映射只作为发卡一维坐标的评分对齐拟合；它不改变图、嵌入或原始扩展。
  • 测试点对照冻结训练图/算子扩展。它们永不被插入直推式重拟合。对圆，测试集是已实现训练角度的精确圆中点集；全部 15 个场景-重复记录的最大中点构造误差为 0.0。
  • 测试弧长、圆角度与余弦–正弦真值只在原始扩展后进入。

验证器受限签名、测试/真值投毒检查与支撑重用检查全部通过，受保护拟合状态或原始恢复最大差异 0.0。

参数选择

重构网络每个场景使用固定架构，每个方法–场景–重复两个预先声明初始化候选。所选候选最小化验证变换坐标 MSE；并列使用较低候选索引。diagnostics.json 包含全部 42 个网络选择记录（七场景 \(\times\) 三重复 \(\times\) 两网络方法）与全部 84 个候选运行。每个记录存储候选索引、完整确定性 PCG64 种子 ID、验证损失、最佳轮次、运行轮次、轮次上限、停止原因、所选候选/种子/损失/轮次与并列规则。selected_validation_mse 与 parameter_count 结果行是验证与架构诊断，不是留出重构得分。

跨 84 个候选运行，49 个在轮次预算停止，35 个在固定耐心规则后停止；42 个所选候选中计数为 26 与 16。隐藏宽度 8 运行有 260 轮上限，而隐藏宽度 18 小样本压力有 340 轮上限。达到 epoch_budget 只意味着在声明上限前没有耐心停止。轮次上限处有限所选模型不自动标记 nonconvergence。基准把 nonconvergence 保留给适用路径引发数值线性代数失败；自然执行产生无。

对参考场景，重复 0/1/2 的所选非线性候选为 0/0/1，验证损失 0.147593/0.0432484/0.0671336；全部所选最佳轮次 260、停止原因 epoch_budget。所选冻结编码器候选为 1/0/0，损失 0.408717/0.513976/0.652788，所选最佳轮次 260/260/259，相同所选停止原因。完整种子 ID 与两个候选的损失、轮次与停止原因在诊断中保持机器可读，而非在结果 CSV 中缩写。

PCA、解析线性自编码器、均值、\(k\)、\(\varepsilon\)、保留圆模态与扩展规则在该实现中没有数据驱动搜索。图场景参数在生成前冻结，永不从留出真值选择。

推断

重构恢复把冻结训练标准化器与冻结方法状态应用于测试观测，返回原始单位六维重构与一维码。冻结编码器在测试时保持固定。

发卡恢复应用冻结 PCA 或 Gower 扩展。Isomap 测试点附着到其 \(k\) 个最近训练顶点而不重建训练图；所得图距离馈入冻结 MDS 扩展。圆恢复对照冻结训练算子使用归一化 Nyström 扩展。

图拟合、最短路径、特征分解与扩展区别于评分对齐与基于真值的诊断。

失效与适用性标签

保留完整任务特定笛卡尔清单：

  • 重构：\(7\times3\times5\times7=735\) 行；
  • 图几何：\(13\times3\times8\times11=3{,}432\) 行；
  • 总计：4,167 个唯一规范行与 1,389 个摘要组。

自然执行产生：

任务 ok inapplicable invalid nonconvergence
重构 690 45 0 0
图几何 299 3,133 0 0
总计 989 3,178 0 0

适用性在数值失败前解决。ok 要求适用有限值；inapplicable 保留方法–度量或真值目标失配；invalid 表示畸形/非有限适用评分；nonconvergence 表示适用路径中的线性代数失败。每个非 ok 行具有机器可读原因且无数值。

自然 invalid 与 nonconvergence 缺失不是全局鲁棒性主张。真实路径故障注入在保留不适用优先级的同时验证两个标签。在断开发卡重复中，Isomap 坐标/MDS 行保持 inapplicable，而非接收捏造坐标。

# 非线性重构与图几何鲁棒性基准测试

## 科学问题

P4-U05 询问两个独立合成问题。

1. **非线性重构：** 在声明弯曲生成器与有界对照下，训练均值、秩一 PCA/线性自编码器、小非线性自编码器与冻结随机编码器对照何时重构留出观测或无噪信号，以及其码如何响应曲率、矩匹配全维高斯、样本/容量压力、干扰方差与支撑移位？
2. **图几何：** 对已知发卡或圆模拟器，外围线性参考、经典 MDS、Isomap、直接图诊断、扩散映射与冻结样本外扩展如何响应采样间隙、捷径、非均匀密度、图连通性、邻域大小、带宽、谱截断与特征度量缩放？

任务具有单独生成器、方法、信息集、适用性规则、度量、摘要与图面板。不计算跨任务归一化、聚合得分、排名或普遍胜者。重构损失、码诊断、图路径误差、算子特征空间误差与留出扩展误差是不可互换目标。

## 真值

### 重构任务

普通重构场景使用标量评分变量 $s\in[-1.5,1.5]$ 与六维无噪映射

$$
f_c(s)=\left[
 s,
 cs^2,
 0.35c\sin(2s),
 0.2cs^3,
 c\left(\cos s-\frac{\sin(1.5)}{1.5}\right),
 0.4c\sin(3s)
\right],
$$

其中 $c$ 是声明曲率。随后添加标准差 $0.06$ 的独立高斯观测噪声。高方差干扰场景向后两个观测坐标添加标准差 $2.4$ 的独立噪声。已知 $s$ 与 $f_c(s)$ 是仅评分真值；它们不被提供给预处理、拟合、选择或重构。

矩匹配高斯场景改为采样参考弯曲信号加观测噪声的总体均值与协方差的满维高斯。它没有标量生成器参数或无噪一维信号目标，因此那些行显式不适用。

一维瓶颈宽度由分析者固定。它不是与模型无关的本征维数估计，生成曲线也不被用作任意观测位于流形上的证据。

### 图几何任务

发卡生成器使用稳定 Phase 3 单位速度平面发卡，等距嵌入三个观测维并添加标准差 `0.01` 的高斯噪声。其评分真值是解析弧长坐标 $\ell$。普通半径继承自稳定 Phase 3 实现；捷径压力使用半径 `0.06`。图构造只接收观测坐标。弧长在拟合后进入图或扩展评分。

圆生成器使用 $(\cos\theta,\sin\theta)$ 的稳定 Phase 3 三维等距嵌入。有限目标是声明训练亲和/马尔可夫算子及其余弦–正弦双模态子空间、完整有限算子扩散距离与冻结 Nyström 扩展。这些是有限图/算子目标，不是推断拓扑或恢复黎曼度量。

## 生成

生成先于拟合且划分特定。

- 重构训练/验证/测试大小为 `120/60/90`，除样本/容量压力（`28/42/90`）。普通 $s$ 值在每个划分内独立均匀于 $[-1.5,1.5]$。在 `support_shift` 中，训练与验证精确为参考捆绑，而测试幅度在 $[1.5,2.35]$ 中随机符号采样。
- 发卡训练/验证/测试大小为 `108/42/54`。采样在弧长中均匀，除非场景声明训练间隙或非均匀密度。度量缩放场景在应用 `diag(1,1,3)` 前重用参考随机抽样。
- 圆训练/验证/测试大小为 `64/32/64`。均匀训练点形成相移正则网格；非均匀训练角度使用均匀抽样的固定幂变换。在每个圆场景与重复中，每个测试角度是两个连续排序训练角度（含环绕区间）之间的精确圆中点。验证是独立保留网格，不用于拟合或选择。度量缩放对相同参考训练/测试角度应用 `diag(1,1,3)`。

两个 Phase 3 源角色刻意不同。稳定非线性重构可执行是**仅哈希设计出处**：它不在运行时加载，且没有 `P3_NL` 数值调用。稳定图几何可执行被加载并**实际复用**于发卡几何、图拟合、最短路径/MDS、扩展、扩散映射、Nyström 与算子诊断。清单与验证诊断分别记录这些角色；两个稳定 Phase 3 源都不被修改。

## 阴性对照与压力情形

- 矩匹配高斯在移除声明标量/无噪重构目标的同时控制第一与第二矩。
- 冻结随机编码器固定其编码器并只训练其解码器，把有用随机非线性特征与学习编码器分开。
- 高容量/小样本与干扰场景暴露架构与损失组成敏感性，而不强迫特定失败故事。
- `support_shift` 使用精确参考训练/验证观测与精确相同拟合状态；只有外部支撑测试捆绑不同。
- 发卡间隙与 $k=1$ 保留断开图与无限最短路径对，而非静默修复连通性。
- 减小支分离、大/近完整邻域与特征缩放暴露捷径与度量依赖。
- 圆密度、带宽与度量缩放场景压力有限马尔可夫算子、谱截断与冻结 Nyström 扩展。

## 解读界限

- 低留出重构误差**不**证明流形、低或本征维数、单射坐标卡、表示、动力学、机制或因果性。
- 一维瓶颈是分析者选择，不是本征维数估计。已知模拟真值上的码相关或低碰撞率不创造唯一坐标。
- 非线性方法在一个弯曲模拟器上优于线性重构基线不蕴含普遍优越性或真实数据有效性。
- 视觉有序 Isomap 坐标、有限图路径准确度或低 MDS 应变**不**证明拓扑、测地线或黎曼几何。
- 扩散映射特征空间是有限算子输出。没有额外假设与证据，它不恢复圆拓扑、流形拉普拉斯、本征维数、物理时间或动力学。
- 连通性是所构造有限图的性质，不是未知潜支撑拓扑连通性的证据。
- 冻结扩展不是直推式重拟合，不必与其一致。
- 三个重复与有界场景不支持显著性、置信度、因果因子隔离或普遍排行榜。
