Flow

Flow

One-sentence definition

A flow is a finite-time evolution family that, where well-defined, maps each initial state in its domain to the state reached after an elapsed time under one shared autonomous continuous-time rule.

Why this concept matters

A vector field gives a local instantaneous rule, while a flow describes its accumulated effect over finite time across possible initial states. Fixing one initial state in a flow yields one trajectory; considering all supported initial states yields a consistent family of trajectories generated by the same dynamics.

This distinction prevents a collection of observed curves from being mistaken for a flow. A flow is not merely a dataset of trajectories: its time-evolution maps must act consistently on states and compose across successive time intervals. Teschl defines the flow of an autonomous differential equation by collecting its integral curves into one map (Teschl 2012, sec. 6.2).

The stable First-Order Autonomous Dynamical System Math Object is the canonical location for the existence, uniqueness, maximal-continuation, and regularity results that justify such maps. This Concept retains only the notation and distinctions needed to interpret finite-time evolution without duplicating those theorem-level derivations.

Intuition

Imagine the vector field as an arrow attached to every state. The flow answers a finite-time question: “Starting from this state, where does the shared rule carry the system after elapsed time \(\tau\)?”

There are two useful ways to hold part of the flow fixed:

  • Fix an initial state \(x_0\): varying elapsed time \(\tau\) traces one trajectory.
  • Fix an elapsed time \(\tau\): the map \(\phi_\tau\) moves every supported initial state to its state after that duration.

A flow is the coherent collection of these finite-time maps, not any unrelated collection of before-and-after pairs.

Formal definition

Consider an autonomous Euclidean system

\[ \dot{x}=f(x),\qquad x\in\mathcal{X}. \]

Suppose the active assumptions provide a unique maximal solution through each supported initial state. For \(x\in\mathcal{X}\), let \(I_x\) be the maximal elapsed-time interval containing \(0\) for the solution through \(x\), and define the supported domain

\[ W = \{(\tau,x)\in\mathbb{R}\times\mathcal{X}:\tau\in I_x\}. \]

The joint finite-time evolution map is

\[ \Phi:W\rightarrow\mathcal{X}, \qquad \Phi(\tau,x)=\phi_\tau(x), \]

where \(\phi_\tau(x)\) is the state reached after elapsed time \(\tau\) from \(x\). For fixed \(\tau\), the corresponding state map has the typed domain

\[ \operatorname{dom}(\phi_\tau) = \{x\in\mathcal{X}:(\tau,x)\in W\}. \]

The supported set need not be all of \(\mathbb{R}\times\mathcal{X}\), and \(\operatorname{dom}(\phi_\tau)\) need not equal \(\mathcal{X}\). The evolution family satisfies

\[ \phi_0(x)=x, \]

and the composition law only where the required evolutions are supported. Explicitly, if \(s\in I_x\) and \(\tau\in I_{\phi_s(x)}\), then \(s+\tau\in I_x\) and

\[ \phi_{\tau+s}(x)=\phi_\tau\bigl(\phi_s(x)\bigr). \]

The first relation says that zero elapsed time leaves the state unchanged. The second says that evolving for \(s\) and then for \(\tau\) agrees with evolving once for the combined elapsed time. It is not a claim that every map is defined on all states or all elapsed times (Teschl 2012, sec. 6.2).

Local existence and uniqueness support this single-valued local finite-time evolution. Under the stronger condition \(f\in C^1\), the stable Math Object states that \(W\) is open and \(\Phi\) is jointly \(C^1\) in elapsed time and initial state; under the adopted LDG convention, this jointly regular map is the generated local flow. The regularity theorem and its derivation remain in the Math Object.

For an initial condition \(x(t_0)=x_0\), the associated trajectory can be written

\[ x(t)=\phi_{t-t_0}(x_0) \]

when \(t-t_0\in I_{x_0}\), equivalently when \((t-t_0,x_0)\in W\). Here \(t\) is absolute clock time, whereas \(\tau=t-t_0\) is elapsed time from the initial condition.

When the active ODE assumptions make each curve \(\tau\mapsto\phi_\tau(x)\) differentiable in elapsed time, it satisfies

\[ \frac{d}{d\tau}\phi_\tau(x) = f\bigl(\phi_\tau(x)\bigr), \]

and its derivative at zero recovers the vector field:

\[ f(x)=\left.\frac{d}{d\tau}\phi_\tau(x)\right|_{\tau=0}. \]

This derivative is along one trajectory with respect to elapsed time. It does not by itself assert differentiability with respect to the initial state \(x\); joint initial-state regularity is the stronger local-flow conclusion above. These relations express the local-versus-finite-time distinction and are not an existence or uniqueness proof.

For a two-sided smooth local flow, reverse elapsed time supplies a local inverse: \(\phi_{-\tau}\) reverses \(\phi_\tau\) on the corresponding supported domains. This does not make \(\phi_\tau\) a globally defined bijection \(\mathcal{X}\to\mathcal{X}\) for every \(\tau\) (Teschl 2012, sec. 6.2).

The one-parameter notation \(\phi_\tau\) is most natural for autonomous dynamics. Semiflows restricted to nonnegative elapsed time, explicitly time-dependent systems, and input-driven evolution are outside this bounded L2 Concept rather than silently treated as the same structure.

Core notation

  • \(\mathcal{X}\): the state space.
  • \(f\): the autonomous vector field or local instantaneous rule.
  • \(x_0\in\mathcal{X}\): an initial state value.
  • \(t_0\): the reference time of the initial condition.
  • \(t\): absolute clock time along a trajectory.
  • \(\tau\): elapsed flow time.
  • \(I_x\): the maximal elapsed-time interval containing \(0\) for the solution through \(x\).
  • \(W\): the supported elapsed-time/state pairs \((\tau,x)\) with \(\tau\in I_x\).
  • \(\Phi(\tau,x)=\phi_\tau(x)\): the joint local finite-time evolution map on \(W\); jointly \(C^1\) under the stated stronger flow condition.
  • \(\phi_\tau\): the finite-time state map on the states for which elapsed time \(\tau\) is defined; its domain may depend on \(\tau\) for a local flow.
  • \(\operatorname{dom}(\phi_\tau)=\{x\in\mathcal{X}:(\tau,x)\in W\}\): the supported states for one fixed elapsed time.
  • \(\phi_\tau(x_0)\): the state reached from \(x_0\) after elapsed time \(\tau\).
  • \(x(t)=\phi_{t-t_0}(x_0)\): the trajectory associated with one initial condition.

The symbol \(\phi\) is conventional. A source may use \(\Phi\), \(T_t\), or another symbol; the defining role and composition property matter more than the letter.

  • State Space: supplies the admissible initial and later states.
  • Trajectory: supplies the time-parameterized evolution obtained by fixing one initial state.
  • Initial Condition: supplies \(x(t_0)=x_0\).
  • Vector Field: supplies the local instantaneous rule in this Cycle’s continuous-time setting.

What this does NOT imply

Calling an evolution family a flow does not by itself imply that:

  • any arbitrary collection of trajectories comes from one shared flow;
  • similar-looking trajectories have identical vector fields or finite-time dynamics;
  • one observed trajectory determines the maps \(\phi_\tau\) for other initial states;
  • finite noisy observations identify a unique flow;
  • a visualization of curves establishes a dynamical mechanism;
  • the flow is defined for every state or for all positive and negative times;
  • every fixed-time map is a globally defined bijection \(\mathcal{X}\to\mathcal{X}\), even though a two-sided smooth local flow has reverse-time local inverses on corresponding supported domains;
  • every vector field automatically generates a unique global flow; or
  • an input-driven or explicitly time-dependent system has the same one-parameter flow structure.

Minimal example

Consider the one-dimensional autonomous rule

\[ \dot{x}=1, \qquad \mathcal{X}=\mathbb{R}. \]

The vector field assigns the same instantaneous rate \(f(x)=1\) at every state. Its flow is

\[ \phi_\tau(x_0)=x_0+\tau. \]

For a fixed elapsed time \(\tau\), \(\phi_\tau\) shifts every initial state by \(\tau\). For an initial condition \(x(t_0)=x_0\), the trajectory is \(x(t)=x_0+(t-t_0)\). The maps compose because

\[ \phi_\tau\bigl(\phi_\sigma(x_0)\bigr)=x_0+\sigma+\tau=\phi_{\tau+\sigma}(x_0). \]

This example separates the objects without adding advanced theory: \(f\) is the local rate, \(\{\phi_\tau\}\) is the finite-time evolution family, and \(t\mapsto\phi_{t-t_0}(x_0)\) is one trajectory in absolute clock time.

Neuroscience / behavioral relevance

Using a population-activity vector as a proposed neural state gives a coordinate setting in which trajectories can be described (Cunningham and Yu 2014). A neural flow claim is stronger: it proposes that population states across supported initial conditions evolve according to one coherent finite-time family. Similar-looking trial trajectories or a pooled trajectory plot do not establish that shared family, especially when inputs, task conditions, or unmeasured state differ.

For behavior, a set of movement traces is likewise not automatically evidence for one behavioral flow. The traces may reflect different control inputs, parameters, state definitions, or measurement processes. Inferring a shared flow from such data is a methodological problem that requires assumptions and evaluation beyond this Concept Object.

Relevance to LDG

At L2, Flow connects the stable Vector Field Concept to the reusable autonomous-system formalism without collapsing the instantaneous rule, one trajectory, an orbit, and the supported family of finite-time maps into one object. This distinction is essential before later recovery tasks can ask whether observed neural or behavioral trajectories support shared dynamics.

Open questions

  • What evidence is sufficient to support one shared flow across trials or conditions?
  • How should uncertainty in initial states and observations propagate into a flow estimate?
  • When should an input-dependent or explicitly time-dependent evolution be represented with notation other than a one-parameter autonomous flow?

These are later inference and modeling questions outside this bounded L2 scope.

# Flow

- $f$: the autonomous vector field or local instantaneous rule.
